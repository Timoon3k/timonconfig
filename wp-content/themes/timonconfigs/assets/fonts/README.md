# Self-hosted fonts

- **Inter**, Latin variable normal, weights 100–900, from `@fontsource-variable/inter` 5.2.8: <https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.2.8/files/inter-latin-wght-normal.woff2>.
- **Barlow Condensed**, Latin bold normal, weight 700, from `@fontsource/barlow-condensed` 5.2.7: <https://cdn.jsdelivr.net/npm/@fontsource/barlow-condensed@5.2.7/files/barlow-condensed-latin-700-normal.woff2>.

Both fonts use the SIL Open Font License 1.1. Exact upstream licenses and copyright notices are included in `Inter-LICENSE.txt` and `Barlow-Condensed-LICENSE.txt`. Font files are served locally by the WordPress theme; rendering needs no external font requests.
