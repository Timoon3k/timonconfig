# TimonConfigs review launch — genuine feedback only

Do NOT populate fake five-star reviews as if actual customers posted them. Polish UOKiK and Google disallow deceptive invented testimonials and fraudulent Review/AggregateRating markup. The TimonConfigs project deliberately labels fallback sample cards as DEMO CONTENT and excludes demo rating schema; keep this protection.

## Legitimate collection flow

1. Ask current eligible users after an actual download / paid access experience for honest feedback; do not pre-select satisfied people or require positive ratings.
2. Allow 1–5 stars + description, actual related config choice (Predator S30, Timon S30 VIP Classic, Timon S30 Roller, verified Matrix configs) and the author's preferred display pseudonym. Check permission to publish handle/quote. Prefer a private form tied to actual Discord ID and a verified access/download record where lawful.
3. If feedback is checked, disclose exactly how: e.g. "We confirm access to the indicated configuration through the connected Discord account before assigning the Verified Member label." This is only a proposal, NOT a claim about current implementation.
4. Store consent, moderation reason, verification result and date privately. Do not expose purchase IDs, Discord snowflakes, purchase timestamps or private order details. Moderate spam/abuse fairly; do not suppress critical genuine feedback because negative.
5. If reviews were given in response to a giveaway/reward/discount, clearly disclose incentives; do not award prizes conditional on positive feedback.
6. Use WordPress **Reviews** custom post type for the genuine approved reviews; disable the Demo flag only after verification. Don't add fictional 5-star count or JSON-LD aggregate ratings.

## Ready-to-send Discord DM (English)

No purchase or positive review is required for giveaways. Thanks!"
