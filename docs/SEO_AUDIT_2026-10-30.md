# TimonConfigs — audyt SEO i Rank Math, 2026-10-30

## Wniosek: indeksowanie a pozycja na wybrane hasło

Właściciel podał, że inspekcja Home w Search Console pokazuje **„URL jest w Google”**. Według tego zgłoszenia strona główna jest zaindeksowana. Brak jej na zauważalnej pozycji dla „xim matrix Apex Legends” lub „cronus zen discord” nie oznacza więc automatycznie braku w indeksie. Nie potwierdzono niezależnie raportu, indeksowania wszystkich podstron, pozycji, ruchu ani Core Web Vitals; brak dostępu do danych Search Console.

Eksport Rank Math ma globalne `index`, włączone mapy XML i URL `https://timonconfigs.com/`. Nie zawiera dowodu globalnej blokady indeksowania. Nie zawiera też indywidualnych metadanych stron, WordPress `blog_public`, rzeczywistych nagłówków HTTP ani raportów Google.

Publiczny odczyt Home, robots.txt, dwóch map, katalogu, kolekcji, Contact, Pricing i dwóch zapytań Google — łącznie12prób — został zatrzymany przez **proxy środowiska, CONNECT403**. Nie uzyskano odpowiedzi serwera TimonConfigs. Nie jest to potwierdzenie HTTP403 witryny, błędu domeny ani blokowania Googlebota. Dowody: `artifacts/seo-live-audit-2026-10-30.json` oraz pliki nagłówków.

## Pliki i import

Zalecany plik: [Rank Math SEO-only](seo/timonconfigs-rank-math-seo-only-2026-10-30.json). Pełna poprawiona kopia: [reviewed](seo/timonconfigs-rank-math-reviewed-2026-10-30.json). Szczegółowe14zmian: [przegląd eksportu](seo/RANK_MATH_EXPORT_REVIEW_2026-10-30.md).

1. Zachowaj aktualny eksport Rank Math i kopię bazy; porównaj go z plikiem użytkownika z2026-10-30.
2. W **Rank Math SEO → Status & Tools → Import & Export** wybierz plik SEO-only. Obejmuje `general`, `titles`, `sitemap`; pomija moduły, role i przekierowania.
3. Importer zastępuje **całe niepuste sekcje**, nie tylko14kluczy. Późniejsze autorskie zmiany wewnątrz tych trzech sekcji mogą zostać zastąpione. Pełny reviewed ponownie zastosuje również zachowane moduły i role — nie jest zalecanym wariantem zwykłej aktualizacji SEO.
4. Sprawdź edytor Rank Math dla statycznej Home i Contact. Indywidualny tytuł, opis, canonical i robots mają pierwszeństwo; eksport ustawień nie nadpisuje ich automatycznie.
5. Po aktualizacji kodu/importu wyczyść cache i sprawdź źródło Home oraz Contact: pojedyncze title/description/canonical, właściwy HTTPS host, oczekiwane robots i działający link Discord. Sprawdź faktyczny `sitemap_index.xml`.

## Co zmierzyć w Search Console

- **Inspekcja URL:** osobno Home, Contact i opublikowana kolekcja Apex. Zapisz wynik, ostatnie pobranie, canonical wybrany przez Google i ewentualny konkretny powód wykluczenia. Dla istotnej zmiany można poprosić o ponowne indeksowanie; nie gwarantuje to terminu ani pozycji.
- **Skuteczność → Wyniki wyszukiwania:** porównaj okresy14–28dni, ustaw kraj i urządzenie odpowiadające odbiorcom, filtruj obie frazy i warianty. Zapisz wyświetlenia, kliknięcia, CTR, średnią pozycję i URL, który otrzymuje wyświetlenia. Brak wyświetleń w krótkim okresie nie dowodzi noindex.
- **Mapy witryn / Indeksowanie stron:** potwierdź odczyt aktualnej mapy i powody pominięcia poszczególnych publicznych URL-i. Wykluczenie konta, checkoutu lub pustej kolekcji jest zamierzone.
- Jeśli inny URL jest wykluczony, sprawdź faktyczne `noindex`/`X-Robots-Tag`, robots.txt, statusHTTP, canonical, ustawienie **Ustawienia → Czytanie → Widoczność dla wyszukiwarek** oraz oba adresy WordPressa. Tych ustawień nie odczytano z produkcji.

Wysokiej pozycji lub TOP1 nie da się zapewnić importem JSON. Największy dalszy wpływ ma przydatna, własna treść odpowiadająca zapytaniu, poprawne działanie strony i naturalne pozyskiwanie odbiorców. Nie stosować kupionych linków, spamowych publikacji ani sztucznych opinii. Ten audyt nie potwierdza wdrożenia zmian na Hostingerze.
